# 設定說明：一個總試算表，每班一個分頁（接收端 v3）

給任何老師使用。**只要設定一次**（約 3 分鐘），之後新增班級、看數據、換電腦都不用再碰 Apps Script，也不用再貼網址。
網站的「[班級清單](../teacher.html)」頁第一次打開就會顯示同樣的圖解步驟。

## 第一次設定（三步）
1. **複製範本試算表**：在班級清單頁按「複製範本試算表」（連到 `https://docs.google.com/spreadsheets/d/<範本ID>/copy`），Google 問「要複製文件嗎？」時按「建立副本」。這份副本就是您的總試算表，接收程式已經裝在裡面。
2. **部署程式**：
   - 副本上方選單「擴充功能」→「Apps Script」。
   - 右上「部署」→「新增部署作業」→「選取類型」旁的齒輪 →「網頁應用程式」。
   - 執行身分：**我**；誰可以存取：**所有人**（學生不用登入就能送；他們只能新增資料，看不到試算表）。按「部署」。
   - 「授予存取權」→ 選帳號 → 出現「Google 尚未驗證這個應用程式」時按「進階」→「前往…（不安全）」→「允許」。這是您自己試算表裡的程式，沒送 Google 審核才會這樣提醒。
3. **把網址貼回來**：部署完成視窗裡「網頁應用程式」網址（結尾 `/exec`）按「複製」，貼到班級清單頁第 ③ 步。網站會馬上自動測試：
   - 「接好了」→ 設定區自動收起來，只剩班級清單。
   - 「第 ③ 步」錯誤 → 貼錯網址（貼成試算表網址、編輯器網址、`/dev` 測試網址或沒複製完整）。
   - 「第 ② 步」錯誤 → 程式是舊版／還沒部署成新版本，或「誰可以存取」不是「所有人」（Google 回登入頁，網站讀不到回應）。
   - 「已經由另一台電腦設定過」→ 請用原本電腦的「我的教師頁」連結。

不設定也能上課：網址欄先空著，學生的紀錄只存在自己的手機，不能送給您（學生可以下載 CSV 交給您）。

## 設定好之後
- **＋新增班級**：輸入班名（例如「301」）按「建立」，總試算表就自動多一個叫「301」的分頁。
- 同一班的雙狹縫、單狹縫在同一頁，用「實驗」欄區分；不適用的欄位留空。
- **看數據**：直接打開總試算表裡那一班的分頁（`…/edit#gid=<分頁編號>`）。
- **編輯**：改班名＝分頁改名，資料和已經發出的學生連結都不變；改縫的設定後，學生用舊連結打開也會拿到新設定。
- **封存**：分頁隱藏起來（不刪），卡片收進「已封存」；學生照樣能送。「還原」就重新顯示。
- **刪除**：只從清單拿掉；試算表分頁和資料都保留，已發出的連結也仍然送得進那一頁。
- **換電腦**：在「老師設定與換電腦」按「複製「我的教師頁」連結」，在新電腦打開它，班級清單會從總試算表取回。連結含老師金鑰，請勿給學生。

## 已經在用舊版（v1／v2）的試算表
不用複製範本，直接換程式，網址不變：
1. 班級清單頁第一次設定區展開「已經有舊版試算表？」，按「複製新版程式」（或打開本資料夾的 `Code.gs` 全選複製）。
2. 舊試算表 →「擴充功能」→「Apps Script」，把 `Code.gs` 全部取代並儲存。
3. 「部署」→「管理部署作業」→ 選原本那一個 → 鉛筆「編輯」→「版本」選「新版本」→「部署」。**不要用「新增部署作業」**，那會產生新網址。
4. 把原本的 `/exec` 網址貼到第 ③ 步（舊教師頁已存網址的話，打開頁面就會自動接上，原本的課堂會自動在總試算表建成分頁）。

相容性：
- 舊長連結（沒有班級編號）的紀錄照舊寫進「雙狹縫」「單狹縫」，欄位與 v1／v2 相同。
- v2 課堂連結（帶 `classCode`）：若總試算表有同編號的班級（舊教師頁的課堂搬過來時會沿用代碼），寫進那一班的分頁；否則照 v2 寫進「課堂名稱-雙狹縫」等分頁。
- 「課堂設定」分頁（v2 留下的）不會被改動。

## 程式介面（給維護者）
- `GET`（無參數）→ `{ok, msg, v:3}`
- `GET ?action=hello&key=` → 第一次登記老師金鑰（指令碼屬性 `TEACHER_KEY:<試算表ID>`），回 `{ok, v, sheetUrl, classes}`
- `GET ?action=list|addClass|editClass|archive|remove&key=&id=&name=&cfg=`（寫入都要金鑰；`archive` 用 `on=1|0`）
- `GET ?action=config&id=` → 學生頁讀班級最新設定（不用金鑰）
- `POST payload=<JSON>` → 學生紀錄；帶 `classId` 寫進班級分頁
- 網址參數**不要用 `c`**（Google 會回 400）。
- 班級清單存在「班級清單」分頁：班級編號、班名、分頁編號（gid）、設定（JSON）、狀態（空白／封存／移除）。請不要手動改。
- 範本試算表的擁有者**不要**用範本本身跑第 ③ 步（金鑰會登記在範本上；複製出去的副本因為試算表 ID 不同，會重新登記，不受影響）。
- 如果老師的「我的教師頁」連結遺失：Apps Script →「專案設定」→「指令碼屬性」刪掉 `TEACHER_KEY:` 開頭那一列，再在教師頁重新貼網址即可。

## 注意
- 學生的姓名與成績只會進**您自己的**試算表。
- 學生連結含有程式網址，拿到連結的人都能送資料進來，請不要公開張貼。
