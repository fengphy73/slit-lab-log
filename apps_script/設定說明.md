# 設定說明：把學生紀錄送進您自己的 Google 試算表

這份說明給任何老師使用。大約 5 分鐘。用您自己的 Google 帳號操作即可，不必架設伺服器。

也可以在網站的「[老師設定](../teacher.html)」頁依畫面步驟操作。

## 五分鐘步驟
1. 打開 <https://sheets.google.com>，按「空白」建立新的試算表。左上角名稱可改成「狹縫實驗紀錄」。
2. 在試算表上方選單按「擴充功能」→「Apps Script」。
3. 刪掉左邊 `程式碼.gs` 裡的預設內容，改貼上本資料夾的 `Code.gs`（老師設定頁也可按「複製接收程式」）。按儲存。專案名稱可改成「狹縫實驗接收端」。
4. 右上角按「部署」→「新增部署作業」→ 類型選「網頁應用程式」。
   - 執行身分：**我**（您的帳號）
   - 誰可以存取：**所有人**（學生不用登入就能送出；他們只能新增資料，看不到試算表）
   按「部署」，依指示授權。若出現「Google 尚未驗證這個應用程式」，按「進階」→ 前往您的專案 →「允許」。這是因為程式是您自己貼的、沒送 Google 審核，屬正常現象。
5. 複製畫面上的「網頁應用程式網址」（結尾是 `/exec`），到老師設定頁貼上，再按「產生學生連結」。把連結或 QR code 交給學生。

若暫時不設試算表，老師設定頁的網址欄可留空。學生仍可把紀錄存在自己的手機，並下載 CSV。

## 之後修改程式
改了 Code.gs 後要「部署」→「管理部署作業」→ 鉛筆圖示 → 版本選「新版本」→「部署」，網址不變。
（若改用「新增部署作業」會產生新網址，就要重新產生學生連結。）

## 注意
- 學生的姓名與成績只會進**您自己的**試算表。
- 學生連結的網址裡含有 `/exec`，任何拿到連結的人都能送資料進來。**請不要把學生連結公開張貼到網路。**
- 試算表欄位包含：收到時間、姓名、班級、座號、組別、日期、照片編號、狹縫片編號、雷射顏色、標示波長、各量測值、學生算出的波長、正確波長、答案是否相符、誤差（給老師看，學生畫面不會顯示）、警告、學生端儲存時間、紀錄編號。
- 同一筆紀錄重送不會重複寫入（以紀錄編號判斷）。
- 若被亂填，可在部署管理中「封存」舊部署再重新部署換網址，並重新產生學生連結。
- 想停止收件：「部署」→「管理部署作業」→「封存」。
- 若您先前已用舊版程式建立試算表，標題列不會自動更新。請改用新的試算表，或刪掉舊的「雙狹縫」「單狹縫」工作表後再送一筆，並重新部署。
