# 狹縫干涉繞射實驗紀錄（網站原型）

學生做「狹縫干涉繞射教具」實驗時，用手機或電腦填寫量測數據，**自己先算出波長**，再按「核對」。網站會代入學生的數字，逐步列出正確算法與單位換算，並告訴學生答案是否相符（允許 ±2% 的四捨五入誤差），以及相對參考波長的誤差。

紀錄存在學生自己的裝置，也可以送進老師的 Google 試算表。

- 不收姓名：只收班級、座號或組別（至少一個）、日期，以及選填的照片編號。
- **雷射顏色必選**：紅光或綠光。參考波長暫定紅光 650 nm、綠光 532 nm（筆上沒寫，已確定用這兩個），寫在 `js/config.js` 的 `LASER_REF`，之後若有標籤再改。誤差%用所選顏色的參考值。同一組可以紅、綠各存一筆。
- **每種量法只量一次**（不再量三次取平均）。
- 雙狹縫干涉：填狹縫片上標示的縫間距 d（不預填）、L、量了幾個間距 n（正整數，預設 10，範圍 1–20）、第 0 條到第 n 條亮紋的總長 → Δy = 總長 ÷ n，λ = dΔy / L。中央亮區看不到 10 條時，可以少量幾個。
- 單狹縫繞射：填狹縫片上標示的縫寬 a（不預填）、L、中央亮紋寬度 W（兩側第 1 條暗紋之間）→ λ = aW / (2L)。
- 學生必填「你算出的波長（nm）」，按「核對」後才顯示正確算法、正確結果、是否相符，以及誤差% = |λ − λ₀| / λ₀ × 100。λ 不在 380–780 nm 時顯示「請檢查單位或量測」（不阻擋）。
- 同一組（同班級＋座號或組別）同一種狹縫，紅、綠都有紀錄時，會顯示比較：兩個波長、綠/紅比值、哪個比較長。還沒記另一色時，會提示「再記一筆」。
- 空白、0、負數、非數字會提示並不計算。

## 檔案結構
```
slit-lab-log/
├── index.html               主頁（基本資料、兩個分頁、我的紀錄）
├── css/style.css            樣式（手機優先）
├── js/config.js             TEACHER_SCRIPT_URL、LASER_REF、LASER_LABEL、LAMBDA_MATCH_TOL_PCT
├── js/calc.js               計算、核對、紅綠比較（網頁與測試共用）
├── js/app.js                介面互動、localStorage、CSV、送出
├── apps_script/Code.gs      Google Apps Script 接收端（雙狹縫、單狹縫各一個工作表）
├── apps_script/設定說明.md  執行長自行建立試算表與部署的步驟
├── tests/calc.test.js       計算與核對測試（node:test）
├── tests/測試紀錄.md        測試結果
├── screenshot_雙狹縫.png    手機尺寸截圖（核對後顯示算法）
├── screenshot_單狹縫.png
└── screenshot_紅綠比較.png  同一組紅、綠都做之後的比較
```

單一檔預覽（把 CSS 與 JS 內嵌進 HTML）在上一層：`/workspace/狹縫實驗紀錄網站_預覽.html`。

## 如何在本機開啟
- 直接用瀏覽器打開 `index.html` 即可（不需安裝、不需建置）。網址加 `#single` 直接開單狹縫分頁。
- 或在本資料夾執行 `python3 -m http.server 8000`，再開 <http://localhost:8000>。
- 執行測試：`node --test tests/calc.test.js`

## 資料儲存
1. **學生裝置**：每筆紀錄存在瀏覽器 localStorage（鍵 `slitLabLog.records.v2`，與舊版三次量測的資料分開），可列出歷次紀錄、刪除單筆、下載 CSV（UTF-8 含 BOM，Excel 可直接開）。每筆記錄同時存學生算出的波長與正確波長。
2. **送出給老師**：以表單 POST（`fetch` + `mode: 'no-cors'`，參數 `payload` 為 JSON）送到 `js/config.js` 的 `TEACHER_SCRIPT_URL`。
   網址空白時按鈕顯示「尚未設定老師的試算表」並停用。送出失敗的紀錄標為「送出失敗」並保留，可整批或單筆重送；接收端以紀錄編號避免重複寫入。
   設定方式見 `apps_script/設定說明.md`。

## 改版說明（2026-11-26）
- 拿掉「量三次取平均」，L、總長、W 都改成只量一次。
- 改由學生先算波長，按「核對」後顯示逐步算法；相符容許 ±2%。
- 新增雷射顏色（紅／綠）與同一組的紅綠比較。
- CSV 與 Apps Script 欄位同步：加入顏色、學生答案、正確值、是否相符；移除 L1–L3、W1–W3 等多次量測欄。
- d、a 改為空白必填，名稱改成「填狹縫片上標示的縫間距／縫寬」，上課依各片標示值填寫。
- 雙狹縫新增「量了幾個間距 n」（預設 10，1–20），Δy = 總長 ÷ n；CSV 與 Apps Script 同步加上 n。

## 照片上傳（擴充位置，尚未實作）
目前只有選填的「照片編號」文字欄。若執行長決定要上傳照片，可在：
- `index.html` 各分頁的「照片編號」欄旁加 `<input type="file" accept="image/*" capture="environment">`；
- `js/app.js` 的 `saveRecord()` 讀取檔案、先壓縮（canvas 縮到約 1280px、JPEG）再存，localStorage 容量約 5 MB，照片建議改存 IndexedDB；
- `sendOne()` 把 base64 一併送出，`Code.gs` 的 `doPost()` 用 `DriveApp` 存到老師雲端資料夾、試算表只記連結。
需注意照片可能拍到學生臉孔（個資），以及 Apps Script 單次請求大小限制。

## 已知限制
- `no-cors` 拿不到 Apps Script 的回應內容，只能判斷「網路有送出」；若 Apps Script 內部出錯（例如網址錯、部署權限不是「所有人」），網站仍會顯示「已送出」。請老師第一次設定後用試算表確認有收到。
- 資料只存在該瀏覽器；清除瀏覽器資料、換手機或用無痕模式會遺失，請提醒學生下載 CSV 或送出。
- 送出網址公開，任何人都可送資料進試算表（不會被讀取）；必要時可換部署網址。
- 座號限 1–3 位數字；班級、組別為自由文字。
