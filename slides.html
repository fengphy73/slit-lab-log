1　架設與對準 0

  1. 雷射、狹縫片夾座、屏幕架排成一直線；量狹縫片到屏幕紙的 L（約 1000 mm），照實際記下
  2. 屏幕紙橫放插到底，灰色「插入槽內」那段藏進槽裡
  3. 先不放狹縫片，移動屏幕架，讓光點落在紅色 0 線上
  4. 放入狹縫片（縫直立），左右微調夾座，讓光打在縫上
  5. 建議：雙縫 d = 0.2、單縫 a = 0.1 或 0.05 mm；換縫：夾座平移約 8 mm，雷射、屏幕不動

⚠️ 雷射不可以對著眼睛，也不可以對著同學。

2　雙狹縫怎麼量

  1. 中央亮紋對準 0
  2. 用鉛筆點出 第 0 條到第 n 條亮紋（一般 n = 10）
  3. 看不清楚時，數到看得清楚的最後一條，n 照實際填
  4. 量 第 0 條到第 n 條的總長（mm），只量一次
  5. 記下 d、L、n、總長；紅光、綠光都要做

3　單狹縫怎麼量

  1. 中央亮紋對準 0
  2. 在中央亮紋兩側的第 1 條暗紋各點一個記號
  3. 量兩個記號之間的距離，就是 W（mm），只量一次
  4. 記下 a、L、W；紅光、綠光都要做

4　先寫紙本，再輸入網頁

  1. 數據先寫在分組紀錄表
  2. 自己算出 λ = ＿＿ mm = ＿＿ nm
  3. 掃下一頁的 QR code，打開實驗紀錄網頁
  4. 照紀錄表一欄一欄輸入 → 按核對 → 按儲存這筆紀錄

屏幕紙量完不要丟，和紀錄表一起交回。
