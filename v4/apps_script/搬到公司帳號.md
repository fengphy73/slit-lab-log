# 總程式 v4：搬到公司 Google Workspace 帳號

所有跟帳號有關的設定只在兩個地方：`Code.gs` 開頭的 `CONFIG`，以及 Apps Script「指令碼屬性」（`ADMIN_KEY`、`FOLDER_ID`、`REGISTRY_ID`）。
程式本身不寫死任何帳號、email 或檔案 ID，所以新帳號照「部署步驟」做一次就會自動建好自己的資料夾和老師清單。

## 建議時機
學期之間搬。已經發給學生的連結裡有舊的 `/exec` 網址，搬完後舊網址那學期還能繼續收資料，等學期結束再關掉。

## 步驟
1. **公司 Workspace 管理控制台**（管理員做一次）
   - 雲端硬碟和文件 → 共用設定：允許與「機構外的使用者」共用（老師多半是學校帳號）。
   - 確認 Apps Script 網頁應用程式允許「所有人」存取（部分機構會限制成只限網域內）。
2. **新帳號部署**：用公司帳號照 `部署步驟.md` 做一次，拿到新的 `/exec`，並在開通頁連線（新的管理者金鑰）。
   若要改資料夾名稱、分享權限（編輯者／檢視者），只改 `CONFIG`。
3. **把舊資料夾分享給新帳號**：舊帳號在雲端硬碟對「狹縫實驗紀錄（各校老師）」資料夾按共用 → 加公司帳號（檢視者即可）。
4. **搬老師**（新帳號）：
   - Apps Script → 專案設定 → 指令碼屬性 → 新增 `OLD_REGISTRY_ID` ＝ 舊「狹縫實驗紀錄_老師清單」試算表網址 `/d/` 和 `/edit` 中間那串。
   - 編輯器上方函式選單選 `migrateFromOldRegistry` → 執行（第一次會要求授權）。
   - 每位老師的試算表會被複製到新資料夾（分頁、班級編號、gid 都不變）、重新分享給老師，並沿用同一個老師編號和金鑰；重跑不會重複搬。
5. **發新連結**：新開通頁「已開通的老師」每位按「複製連結」寄給老師。老師打開新連結，班級都在，按「開啟簡報」或「複製學生連結」就是新網址。
6. **學期結束後**：舊帳號的部署作業可以封存（部署 → 管理部署作業 → 封存）。舊試算表要不要刪，依資料使用說明的保存期限決定。

## 注意
- 學校帳號和公司帳號是不同網域，Google 不允許把檔案「擁有者」轉過去，所以用「複製」而不是轉移。
- 搬完後舊試算表不會被改動；新帳號那份是複本。
- `CONFIG.RECORD_STORE` 預留 `'form'`（改寫進自動建立的 Google 表單）、`'shard'`（依老師分散到其他帳號的接收程式）；老師清單的「接收程式網址(預留)」欄有值時，開通頁產生的老師連結會改用那個網址。目前都還沒實作，維持 `'sheet'`。
