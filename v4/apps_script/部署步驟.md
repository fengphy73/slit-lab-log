# 總程式 v4：部署步驟（管理者只做一次）

> 草稿：真實畫面的截圖之後在真環境補上。全部 18 下點擊、4 個快捷鍵，約 5 分鐘。
> 開通頁網址：https://fengphy73.github.io/slit-lab-log/v4/admin.html

## A. 建專案、貼程式（3 下）
1. 打開開通頁 `admin.html`，按 **「① 開新的 Apps Script 專案」**（會開 script.google.com/create，用要當管理者的帳號登入）。……1 下
2. 回開通頁按 **「② 複製總程式」**。……1 下
3. 在 Apps Script 編輯器的程式區點一下，按 **Ctrl+A → Ctrl+V** 蓋掉預設內容，再按 **Ctrl+S** 存檔（上方沒有紅色錯誤就好）。……1 下＋3 個快捷鍵

開通老師時，Google 會寄一封「已與您共用」的通知信給那位老師，老師從信裡也找得到自己的試算表。

## B. 部署成網頁應用程式（約 13 下）
4. 右上 **部署** → **新增部署作業**。……2 下
5. 「選取類型」旁的 **齒輪** → **網頁應用程式**。……2 下
6. 「執行身分」維持 **我**；「誰可以存取」點開 → 選 **所有人**。……2 下
7. 按 **部署** → **授予存取權** → 選自己的帳號。……3 下
8. 出現「Google 尚未驗證這個應用程式」：**進階** → **前往…（不安全）** → **允許**。……3 下
   （這是自己帳號裡的程式，沒送 Google 審核才會這樣提醒；學校帳號有時不會出現這個畫面，就直接跳過，少 3 下。）
9. 「網頁應用程式」網址（結尾 `/exec`）旁按 **複製**。……1 下

## C. 接上開通頁（2 下）
10. 回開通頁，點「總程式網址」欄，**Ctrl+V** 貼上 → 自動連線，出現「✅ 連上了！」。……1 下＋1 個快捷鍵
    這一下會自動：登記這個瀏覽器為管理者（指令碼屬性 `ADMIN_KEY`）、在雲端硬碟建資料夾「狹縫實驗紀錄（各校老師）」和「狹縫實驗紀錄_老師清單」試算表。
11. 按 **「複製『管理者連結』」**，存成書籤（換電腦用它打開）。……1 下

**合計：18 下點擊＋4 個快捷鍵。**

## 之後更新程式（網址不變）
貼上新程式並存檔 → **部署** → **管理部署作業** → 鉛筆 **編輯** → 版本選 **新版本** → **部署**。

## 找不到管理者金鑰時
- 用書籤裡的「管理者連結」打開開通頁就好。
- 或到 Apps Script **專案設定（齒輪）→ 指令碼屬性**，複製 `ADMIN_KEY` 的值，貼到開通頁出現的「管理者金鑰」欄。
- 要換一把：刪掉 `ADMIN_KEY` 那一列並儲存，下一個打開開通頁並連線的瀏覽器會變成管理者（刪完請馬上自己連線）。

## 開通一位老師（3 下）
打開開通頁（書籤）→ 點 email 欄、輸入老師 email → 按 **開通** → 按 **複製連結**，用 email／LINE 傳給老師。
要填老師名稱多 1 下（共 4 下）。同一個 email 再按開通，會拿回原本那位老師，不會多建一份。
已開通清單裡可以「複製連結」（重新取得）、「打開試算表」、「停用／重新啟用」。
